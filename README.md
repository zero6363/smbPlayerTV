# SMB 播放器 TV

通过 SMB 协议直接播放局域网（NAS / 共享文件夹）中视频的 **Android TV 播放器**，
由手机版 [SMB 播放器](../smbPlayer) 复刻而来，专为电视大屏与遥控器操作设计。

## 与手机版的差异

| 项 | 手机版 | TV 版 |
| --- | --- | --- |
| 最低系统 | Android 8.0（API 26） | **Android 5.0（API 21，核心库脱糖）** |
| 操作方式 | 触摸手势（滑动调进度、长按倍速、双击） | **遥控器 D-pad 全键位** |
| 截取帧 | 支持（上一帧/下一帧/导出 PNG） | **已移除** |
| 主页 | 服务器 + 收藏（列表） | **正方形宫格（6 列）：最近播放 12 条 + 收藏 + 服务器** |
| 视频渲染 | TextureView | SurfaceView（低配盒子更流畅） |
| 主题 | 浅色/深色跟随系统 | 统一深色，全屏横屏 |

## 遥控器键位（播放页）

方向键的用途由**当前界面状态**决定（与 VLC `VideoPlayerActivity` 的 `isShowing` 分流、
Compose TV 播放器「控制栏显示时方向键让位焦点」的做法一致），不再全局固定绑死一个动作：

| 状态 | 左右键 | 上下键 | 确认键 |
| --- | --- | --- | --- |
| 弹窗（播放列表 / 倍速 / 删除 / 错误） | 弹窗内选择 | 弹窗内选择 | 点击选中项 |
| 控制条显示（按钮焦点模式） | 在按钮间左右移动焦点 | 在按钮间循环切换焦点 | 点击选中按钮 |
| 控制条隐藏（画面模式） | 预览式快退 / 快进 | 呼出控制条并落到播放/暂停按钮 | 播放 / 暂停 |

- **画面模式左右键**：短按 ±10 秒；按住 ≥400ms 进入连跳（每 250ms ±30 秒），
  屏幕实时预览落点，**松开才真正 seek**（SMB 网络流 seek 昂贵，不能连发）；不弹控制条
- **菜单键**：呼出 / 收起控制条，显式切换上面两种模式；刚切进控制条时底部提示一次
- **返回键**：先收起控制条；再连按两次返回退出播放（提示「再按一次返回退出」，不弹窗）
- **媒体键**（播放/暂停/快进/快退/上一集/下一集）：直接支持；快进/快退不弹控制条，
  避免刚快进完左右键的语义就变了。音量用遥控器自带音量键
- 列表页：长按确认键 = 多选 / 删除 / 编辑等操作；进入文件夹后自动定位到第一条（列表滚到顶部）
- 浏览页：菜单/设置键 = 焦点跳到顶部工具栏按钮
- 播放列表：打开后焦点落在当前播放项，方向键选择、确认键切换

## 功能

- 服务器管理（匿名 / 账密登录、完整路径粘贴直达）、共享自动扫描与切换
- 目录浏览、排序（名称/大小/时间）、多选删除、收藏路径
- 直接流式播放：ExoPlayer + 自定义 `SmbDataSource`，不落盘缓存
- 播放记录自动续播；同目录视频组成播放列表，播完自动下一个
- 同名字幕自动加载（.srt/.ass 等，叠加层渲染）
- 主页「最近播放」：最近 12 条（两排），一键续播；长按确认键删除记录
- 播放容错：源文件个别帧/片段损坏时自动跳过 1.5 秒继续播（同一处最多连试 4 次），
  片尾出错按播放完毕处理；解码器开启失败回退（硬解失败自动换软解）。只有解码器初始化失败、
  格式不支持、文件不存在/无权限这类「换位置也没用」的错误才弹窗

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

依赖本机 `D:\code\sdk`（JDK / Gradle 8.9 / Android SDK），签名使用 `D:\code\sdk\signing` 统一 keystore，
产物输出到 `output\app-release.apk`。
